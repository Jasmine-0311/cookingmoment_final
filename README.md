# 此食此刻

一個多人協作開發的純切版電商網站，從線稿發想到切版上線，完整走過一輪團隊合作流程。

---

## 📌 專案簡介

此食此刻是一個模擬電商購物流程的網站，涵蓋首頁、產品列表、產品詳細、購物車、結帳到結帳完成的完整購物路徑。
專案由多人協作開發，從專案題目的發想、使用者故事的討論與撰寫、wireframe的繪製以及與設計師的溝通到切版協作及發表等流程完整的走過一遍。
我負責**線稿設計、頁面流程規劃**，並**獨立切版開發產品列表頁與購物車頁面**。

## 🧩 我的負責範圍

| 項目 | 內容 |
|---|---|
| Wireframe | 全站線稿繪製，交由設計師產出視覺稿 |
| 產品流程 / 頁面佈局 | 主要規劃者 |
| 切版開發 | 產品列表頁、購物車頁面（獨立完成） |
| 團隊協作 | Git 版本控制、分支管理、跨能力落差溝通協調 |

## 🛠️ 技術棧與架構

- **建置工具**：Vite
- **CSS 框架**：Bootstrap
- **開發方式**：Component-based（原子化元件拆分，UI 依原子 / 分子 / 組織層級拆分共用元件）
- **設計系統**：`_variables.scss` 統一管理色系、字體變數，確保多人開發下視覺一致性
- **版本控制**：Git / GitHub，分支開發、PR 合併

## 📄 頁面架構

```
首頁 → 產品列表頁 → 產品詳細頁 → 購物車 → 結帳頁面 → 結帳完成頁面
```

## 🤝 團隊協作與問題處理

多人協作過程中遇到成員技術落差、時間壓力、以及中途有成員退出的狀況：

- 因應人力缺口，額外承接 2 個頁面的切版開發
- 針對 Git 操作不熟悉的成員，透過多次同步會議統一協作流程、排解版本衝突
- 以會議取代零散溝通，確保進度與規格對齊
